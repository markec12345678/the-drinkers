# THE DRINKERS — Official Website

Professional band website and merchandise storefront for The Drinkers from Litija, Slovenia.

## Stack
- Next.js 16 App Router
- React 19
- TypeScript
- CSS-first responsive UI
- Vercel-ready

## Content
The public historical copy is based on documented sources. Dates, members, releases and future concert dates must be verified before publication.

## Important
No payment provider or checkout credentials are included. The shop currently demonstrates the complete product browsing/cart UX without pretending that payment processing is live.

## Development
```
npm install
npm run dev
```
